E-commerce Return Rate Analysis (Power BI)

Project Overview
This project focuses on analyzing return rates in an e-commerce business using Power BI. The goal is to identify patterns in returned orders based on product categories, customer demographics, payment modes, shipping types, and return reasons.

The dataset is sourced from Kaggle and has been cleansed and transformed for visualization. The interactive dashboard provides actionable insights to reduce return rates and improve customer satisfaction.


Tools & Technologies Used
- Power BI Desktop(Data Modeling, DAX, Visuals)
- Power Query Editor (ETL & Data Cleansing)
- Excel(Raw Data Source)
- DAX(for KPIs and measures)


Dashboard Features
- KPIs: Total Orders, Return Rate %, Returned Orders, Net Revenue
- Category Analysis: Return % by Product Category (Fashion, Electronics, etc.)
- Customer Demographics: Age Group & Gender-wise Return Rates
- Payment Analysis: Return trends by COD, Credit/Debit Cards, Wallets
- Shipping Method: Impact of shipping type on return behavior
- Return Reasons: Most frequent causes of returns

Key Insights
- Fashion and Footwear have the highest return rates.
- Age group 25–35 shows the most return activity.
- Cash-on-Delivery (COD) orders are 30% more likely to be returned.
- Wrong Size and Late Delivery are the top return reasons.
- Prepaid orders have a lower return rate than COD orders.
